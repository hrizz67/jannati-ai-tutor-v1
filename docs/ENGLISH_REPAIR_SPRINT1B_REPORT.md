## Explanation of Unavoidable Repetition

Prepositions are a closed grammar set, so some topical reuse of words like *under*, *on*, *in*, *between*, *near*, *behind*, *in front of*, and *above* is expected for Year 2 practice.

What changed in this sprint is the **exact answer-pattern repetition**: the topic no longer reuses the same short answer strings in a repeated drill chain. Instead, each item now uses a full sentence answer with a different context, which gives learners better grammar exposure and gives the bank a cleaner structure.
