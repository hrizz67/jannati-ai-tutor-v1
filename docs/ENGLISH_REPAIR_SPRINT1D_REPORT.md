## Unavoidable Repetition

Verbs naturally repeat the idea of “action words,” so some recurring classroom-style wording is normal in a Year 2 bank. What we removed was the heavy repeated drill pattern where the same short sentence frame and the same small answer set kept coming back again and again.

In the repaired set, the repetition that remains is educationally useful, while the harmful template repetition has been removed.
